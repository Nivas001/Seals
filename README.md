# AARRKKAA International

![AARRKKAA Hero Image](src/assets/hero-mechanical.jpg)

**AARRKKAA International** is a premier supplier and distributor of industrial components including pumps, mechanical seals, elastomers, stainless steel fittings, and precision components for the food, pharmaceutical, chemical, and process industries across South India.

This project is the official web portal for AARRKKAA International, built for extreme performance, clean aesthetics, and reliability.

## 🚀 Live Preview
**[aarrkkaa-seals.vercel.app](https://aarrkkaa-seals.vercel.app)**

## 🛠️ Technology Stack
This project leverages a modern, cutting-edge web development stack to deliver a fast, SEO-friendly, and highly interactive user experience.

- **Framework**: [TanStack Start](https://tanstack.com/start/latest)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [TanStack Router](https://tanstack.com/router/latest)
- **Deployment Engine**: [Nitro](https://nitro.unjs.io/) (Configured for Vercel)

## ✨ Key Features
- **Modern & Responsive Design**: Seamlessly adapts to mobile, tablet, and desktop screens with custom Tailwind CSS configurations.
- **Server-Side Rendering (SSR)**: Built with TanStack Start for lightning-fast initial load times and maximum SEO performance.
- **Dynamic Product Catalog**: Browse through 12+ categories and 100+ SKU lines including mechanical seals, pumps, and silicone products.
- **Interactive Animations**: Smooth scroll animations, bento-grid layouts, and interactive components powered by Framer Motion.
- **Instant Quotation System**: Direct WhatsApp integration for rapid response times.

## 📦 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Bun](https://bun.sh/) or [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/Nivas001/Seals.git
cd Seals
```

### 2. Install dependencies
```bash
bun install
# or npm install
```

### 3. Run the development server
```bash
bun run dev
# or npm run dev
```
The application will be available at `http://localhost:3000`.

## 🏗️ Build for Production
To build the project for production (configured out-of-the-box for Vercel deployment):
```bash
bun run build
```
The build output will be generated in the `.vercel/output` directory.
